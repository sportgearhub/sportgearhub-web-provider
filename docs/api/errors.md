# Коды ошибок API

Каждая ошибка приходит как `ProblemDetails` с полем `code`. По нему и надо ветвиться:
текст сообщения может измениться, код — нет.

```json
{
  "title": "Эта почта уже привязана к другому аккаунту.",
  "status": 409,
  "detail": "Эта почта уже привязана к другому аккаунту.",
  "instance": "/api/v1/auth/email/attach/start",
  "code": "auth.email_taken_by_another_account"
}
```

Статус по умолчанию — **400**, если у кода ниже не указано иное: его задаёт место броска,
а не сам код, и один код может прийти с разными статусами. Ошибки валидации полей приходят
как `400` с объектом `errors` вместо `code`.

Этот файл собран из `ApiErrorCodes` и `ApiErrorMessagesRu`. Править его руками
бессмысленно — тест `ApiErrorReferenceTests` сверяет его с кодом и падает, когда они
расходятся.
